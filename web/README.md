# MottaFit Web

Interface web moderna e responsiva para o sistema MottaFit de gestão de treinos.

## 🚀 Tecnologias

- **React 18** com TypeScript
- **Tailwind CSS** para estilização
- **React Router** para navegação
- **Axios** para integração com API
- **Lucide React** para ícones

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm start

# Build para produção
npm run build
```

## 🎯 Funcionalidades

### Professor
- ✅ Login seguro
- ✅ Dashboard com estatísticas
- 🔄 Criar/gerenciar exercícios
- 🔄 Criar/gerenciar treinos
- 🔄 Convidar alunos

### Aluno
- ✅ Login seguro
- ✅ Cadastro via convite
- 🔄 Visualizar treinos
- 🔄 Acompanhar progresso
